# Solar Copilot: установка

Нужен Mac на Apple Silicon с macOS 13 и новее и подписка Claude Pro или Max.

## 1. Открыть приложение

Приложение подписано без сертификата Apple, поэтому macOS при первом запуске скажет «разработчик не подтверждён». Это нормально, делается один раз:

- Распакуйте архив из Releases и перенесите `SolarCopilot.app` в «Программы».
- В Терминале:
  ```bash
  xattr -dr com.apple.quarantine /Applications/SolarCopilot.app
  ```
- Запустите двойным кликом. В меню-баре появится 🎙.

Без терминала: правый клик по приложению, «Открыть», в диалоге ещё раз «Открыть». На новых macOS кнопка в Системных настройках, «Конфиденциальность и безопасность», внизу «Открыть всё равно».

## 2. Claude Code (подсказки и сводка)

Подсказки идут по вашей подписке Claude, отдельно платить не надо.

- Установите Claude Code: https://claude.ai/code
- В Терминале выполните `claude login` и войдите своей подпиской.

## 3. whisper (расшифровка речи, локально)

- Нужен Homebrew (https://brew.sh, одна команда).
- В Терминале: `brew install whisper-cpp`
- Модель: меню-бар, «⚙ Готовность копилота…», кнопка «Скачать модель (~1,6 ГБ)». Один раз, прогресс виден в иконке.

## 4. Разрешения

- При первой записи macOS спросит доступ к микрофону, разрешите.
- Для диктовки (правый Cmd) и раскладки (левый Option) нужны «Мониторинг ввода» и «Универсальный доступ». Меню «⌨︎ Диктовка…» проведёт.
- Для «Видеть экран по ходу» (копилот смотрит демо или таблицу клиента) нужна «Запись экрана». Можно не включать.

## Проверка

Меню-бар, «⚙ Готовность копилота…»: должно быть три галочки, claude, whisper, модель. Нажмите «Старт», скажите пару фраз, в окне транскрипта появится текст.

## Если что-то не так

- «⚙ Готовность копилота…» показывает, чего не хватает.
- Логи: `~/Library/Logs/solar-copilot*.log`.
- Раскладка работает без всего остального. Если не сработала, проверьте разрешение «Мониторинг ввода».
